## iOS task

Establish and cite the current iOS distribution and install-time compatibility setup before building: how the build reaches users, the deployment target and device capability declarations that decide which devices may install it, and the store listing metadata that carries them. Record that as the baseline, then configure the QACR iOS build and its store entry to match it.

Milestone 3 covers FR-PLT-002, FR-PLT-003 and FR-PLT-004. FR-PLT-001 lands at milestone 4.

## Android task

Establish and cite the current Android distribution and install-time compatibility setup before building: how the build reaches users, the manifest and Gradle declarations (minimum SDK, required features, screen and ABI filters) that decide which devices may install it, and the store listing metadata that carries them. Record that as the baseline, then configure the QACR Android build and its store entry to match it.

Milestone 3 covers FR-PLT-002, FR-PLT-003 and FR-PLT-004. FR-PLT-001 lands at milestone 4.

## Acceptance criteria

1. **automatable** — The QACR build's declared install-time compatibility values (minimum OS version, required device capabilities and feature declarations) equal the values recorded in the cited baseline. Assert against the build configuration in CI.
2. **manual** — The store listing's distribution and compatibility settings match the cited baseline. Requires signed-in review of the store console, which no test harness can reach.
3. **manual** — A device outside the declared compatibility set is not offered the install from the store. Requires a real store account on a real out-of-range device.
4. **manual** — At milestone 4, the build is obtainable only through the platform store route recorded in the baseline for FR-PLT-001. Requires attempting the non-store routes by hand.
